# Fortis Android app

See [../README.md](../README.md) for what the app does and how to build it.

```text
app/src/main/java/com/fortis/mobile/
├── data/        paired laptops (DeviceRepository)
├── keys/        per-pairing Keystore keys, fingerprint-gated signing
├── network/     signed OkHttp client, remote input, telemetry, downloads
├── pairing/     QR pairing with fingerprint check
├── service/     events WebSocket (foreground service), boot restart
├── sudo/        sudo approval notification + full-screen prompt
├── vault/       phone vault: local key, store, sync
├── encrypt/     vault, authenticator and generator screens
├── autofill/    Android autofill service (fill + save)
├── webcam/      Tailscale-only MJPEG server + screen
└── ui/          the other screens
uniffi/fortis_bindings/   generated by ../scripts/build-rust.sh
```
